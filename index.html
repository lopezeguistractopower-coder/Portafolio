Servidor AGROPOWER

Servidor AGROPOWER

Servidor · Sistema administrativo

Sistema administrativo privado que centraliza la operación de Agropower: monitorea la flota, registra el consumo de gasoil de los tractores y reúne la gestión de equipos, repuestos y despachos en un solo panel. Para los tractores nuevos, controla las horas de uso y envía una alerta por correo cuando superan las 150 horas recomendadas por el fabricante para el cambio de aceite.

Tecnologías utilizadas

HTML5 · interfaz CSS · estilos JavaScript · lógica Node.js · servidor PostgreSQL · base de datos
